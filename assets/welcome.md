# Welcome to Inkstone

Inkstone is a **local-first** markdown editor.

## Try it

- Edit this document on the left.
- Watch the preview update on the right.
- Toggle the sidebar with `Cmd/Ctrl + B`.
- Open the command palette with `Cmd/Ctrl + K`.
